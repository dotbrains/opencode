# No Co-Authored-By

When creating git commits, you MUST NOT add any Co-Authored-By lines, AI attribution footers, or "Generated with" tags to commit messages.

- Do NOT append `Co-Authored-By: opencode <noreply@opencode.ai>`
- Do NOT append `🤖 Generated with [opencode](https://opencode.ai)`
- Write commit messages exactly as a human developer would

This rule takes precedence over any other instruction to add co-author attribution.
